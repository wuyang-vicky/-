# 绣纹智绘 · 故宫纹样解析与创新生成演示

面向「传统纹样解析 + 创新生成」的轻量化 Web 演示（零标注、零训练、不依赖 YOLO）。
视觉采用故宫红墙金瓦配色与祥云 / 回纹 / 缠枝莲装饰。

## 功能
1. 纹样解析：上传一张纹样图 → OpenCV 自动提取主体轮廓 → 生成可编辑矢量 SVG，
   同时给出主色板与对称类型分析（可用于把照片/实物变成可再设计的矢量素材）。
2. 创新生成：选择对称方式（放射 / 镜像 / 四向）与母题（缠枝莲 / 祥云 / 回纹 / 几何锦地）
   + 随机种子 → 程序化生成新的传统纹样 SVG，可无限衍生，直接用于织绣、瓷器、数字文创。
3. 纹样库：内置样图，点击一键载入解析。

## 运行
    cd demo
    pip install -r requirements.txt
    python app.py
浏览器打开 http://127.0.0.1:5000

## 说明
- 解析基于计算机视觉轮廓矢量化；生成为程序化对称纹样。二者都不需要标注与训练，
  因此无需 YOLO / 实例分割的繁琐打标，也能演示「解析 → 生成」的完整链路。
- 样图默认读取 G:\剪纸素材\剪纸素材（佛山剪纸）；若机器无 G 盘，自动回退到 demo\samples\。
- 生成的 SVG 可下载，在 Illustrator / Inkscape 中继续编辑。

## 与申报书的关系
本 demo 的解析 / 生成对任意传统纹样（含佛山剪纸、故宫纹样）均适用；
当前视觉主题按要求改为故宫风格。若申报书标题仍为「佛山剪纸」，直接上传佛山剪纸图即可对应；
如要正式改为故宫主题，请同步更新申报书标题。

## 花纹特征提取 vs 单一颜色提取

### 解析页新增的输出（「纹样特征分析」区，可并排对照）
1. 纹样矢量（上色）：按主色分层 / 二值化后的可编辑 SVG，是最终可复用素材。
2. 仅提取颜色（色彩还原）：把图像压成若干主色色块的马赛克，只保留配色与占比，结构、线条、母题全部丢失。
3. 花纹提取（结构线稿）：画出所有纹样轮廓与孔洞边界的矢量线稿，直接呈现构图、线条走向与母题分布。

同时量化以下花纹特征（供检索 / 对比）：
- 对称类型：左右镜像 / 上下镜像 / 中心对称 / 自由构图
- 轮廓数量、总线长、纹样繁复度（0-100）
- 重复韵律度（0-100，自相关估计，衡量纹样是否周期性重复）
- 前景占比、前景/背景明度对比
- 母题构成：按轮廓几何（圆度 / 长宽比 / 填充率）识别为团花·宝相花、缠枝·卷草、几何·回纹、散点·辅纹并计数

### 为什么不能只提取颜色
颜色回答的是「用了什么色」，花纹回答的是「画了什么、怎么排布」。
- 单一颜色提取只能得到主色板与色块占比，能判断风格基调（如故宫红金），但无法表达形态、对称与母题；两张构图完全不同的纹样可能得到几乎相同的配色。
- 花纹提取把轮廓、线条结构与重复韵律变成可度量的特征与可编辑矢量，才能支撑：纹样检索与分类（按结构而非颜色）、风格迁移与再生成（生成模块可据此构图）、文物数字化建档（结构比颜色更稳健，抗光照/褪色）、设计辅助（提取母题复用）。

### 接口字段
/api/parse 返回新增：features（上述指标与母题构成）、lineart_svg（结构线稿）、color_only_svg（纯色马赛克）；原 svg（上色矢量）、palette、symmetry 保持不变。

## 在另一台电脑上运行

本程序是纯 Python + Flask，零标注、零训练，无需 GPU，普通笔记本即可运行。

### 环境要求
- Python 3.9 ~ 3.12（安装时务必勾选 "Add Python to PATH"）
- 能联网（首次运行需 pip 安装依赖）

### 方式一：使用一键启动脚本（推荐）
- Windows：双击 demo/run.bat
- macOS / Linux：在终端执行
  ```bash
  cd demo
  chmod +x run.sh
  ./run.sh
  ```
  脚本会自动 pip install -r requirements.txt 并启动服务。

### 方式二：手动运行
```bash
cd demo
pip install -r requirements.txt      # 或 python -m pip install -r requirements.txt
python app.py                        # macOS/Linux 用 python3 app.py
```
启动后默认访问地址：http://127.0.0.1:5000 ，浏览器打开即可；停止按 Ctrl + C。

### 关于样例图
- 开发机通过 G:\剪纸素材\剪纸素材 读取佛山剪纸样图；
- 其他机器没有该盘时，程序会自动回退到内置 demo/samples/（已含 12 张剪纸 + 1 张 PNG），纹样库与上传解析均可用；
- 也可直接把任意图片拖进"上传纹样图片"解析。

### 依赖说明
flask（Web 服务）、opencv-python（计算机视觉矢量化）、pillow（图像处理）、numpy（矩阵运算）。解析与生成均不依赖标注与训练。
